\chapter{Versione 5}

\section{Obiettivi e Requisiti}
La quinta e ultima versione affianca alla modalità interattiva una \textbf{modalità batch}: il Configuratore può fornire un file di testo strutturato all'avvio, contenente comandi per creare massivamente categorie, campi e proposte senza passare per il menu.

\section{Modalità Batch}

\subsection{Formato del File}
Il file batch è un file di testo semplice (es. \texttt{batch.txt}) in cui ogni riga contiene un comando separato da punto e virgola (\texttt{;}). Le righe vuote e i commenti (che iniziano con \texttt{\#}) vengono ignorati.

\begin{verbatim}
# Commento: crea una nuova categoria
CREA_CATEGORIA;NomeCategoria;Descrizione[;NomeParent]

# Aggiunge un campo alla categoria
AGGIUNGI_CAMPO;NomeCat;NomeCampo;Descrizione;OBBLIGATORIO|OPZIONALE;TIPO

# Crea una proposta (Data nel formato dd/MM/yyyy, Ora HH:mm)
CREA_PROPOSTA;Cat;Titolo;DataConclusiva;TermineIscrizione;Ora;Luogo;NumPart;Quota

# Pubblica una proposta valida già creata
PUBBLICA_PROPOSTA;Titolo
\end{verbatim}

dove \texttt{TIPO} può essere: \texttt{STRINGA}, \texttt{INTERO}, \texttt{BOOLEANO}, \texttt{DATA}, \texttt{ORA}.

\subsection{Esecuzione}
Il file batch può essere utilizzato in due modi:
\begin{enumerate}
    \item \textbf{Argomento da riga di comando} (all'avvio):
    \begin{verbatim}
java -cp bin it.unibs.ing.view.MainCLI data/batch.txt
    \end{verbatim}
    I comandi vengono elaborati prima che si avvii il loop interattivo.
    \item \textbf{Voce 7 del menu Configuratore}: \textit{Importa da File Batch}. Permette di specificare il percorso del file all'interno della sessione interattiva.
\end{enumerate}

\subsection{Output Batch}
Per ogni comando, il sistema stampa \texttt{[OK]} o \texttt{[ERRORE]} con un messaggio descrittivo. Al termine, viene mostrato un riepilogo: \textit{N OK, M ERRORI}.

\section{Architettura (V5)}
\begin{itemize}
    \item \textbf{\texttt{ImportatoreBatch}} (NEW — \texttt{it.unibs.ing.storage}): legge il file riga per riga, effettua il parsing e delega le operazioni ai controller esistenti (\texttt{GestoreCategorie}, \texttt{GestoreProposte}). Tutti gli errori vengono gestiti localmente \textbf{senza interrompere} l'elaborazione delle righe successive.
    \item \textbf{\texttt{GestoreProposte.getProposteValide()}} (NEW): mappa temporanea in memoria per le proposte create ma non ancora pubblicate durante una sessione batch.
    \item \textbf{\texttt{MainCLI.main()}} (MODIFIED): accetta un argomento opzionale (\texttt{args[0]}) con il path del file batch, processato prima del loop interattivo.
\end{itemize}
